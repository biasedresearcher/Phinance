# Phinance

A responsive Next.js + Tailwind personal finance PWA starter using mock data, ready for a future Supabase backend.

## Features

- Dashboard with current-month income vs expenses and category-wise Recharts breakdown
- Expense logging (amount, category, date, note)
- EMI tracker (amount, monthly instalment, interest rate, start date, computed remaining instalments)
- Investments tracker for SIP and lump-sum entries with current value
- Monthly salary entries list

## Run locally

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
